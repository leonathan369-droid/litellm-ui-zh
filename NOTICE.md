# Notice

This repository contains an independent browser-side Simplified Chinese
translation overlay and its installer. It does not contain LiteLLM source code,
the LiteLLM WebUI static bundle, model credentials, or proxy configuration.

LiteLLM is a separate project maintained by BerriAI:
<https://github.com/BerriAI/litellm>.

Install LiteLLM separately and review its current license before deployment.
